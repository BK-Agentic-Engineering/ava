## Policy, limitations and next handoff

The frozen normalizer is **`nfc-lower-punctuation-space-v1`**: NFC → lowercase → Unicode P* punctuation to spaces → whitespace collapse; preserve diacritics, number forms, fillers and repetitions. WER is corpus Levenshtein edits on whitespace tokens; CER uses normalized Unicode code points without spaces. Divide summed edits by summed reference denominators, never average utterance rates. Successful empty hypotheses and explicit inference failures retain all reference denominators; missing/duplicate/unknown IDs block validation. No numeric-equivalence rule changes headline scoring.

Preserve these boundaries:

- Reference agreement is measured; semantic equivalence, intent/slot accuracy, SLU-F1 and LifeMate task/state success are not. Fluency and selected span wins do not settle fidelity or deployment selection. No error mechanism is attributed to FP16, accent, noise or provider internals.
- ViMD retains all three `speaker_overlap_valid` records; observed metadata overlap is not proof of training leakage. Its 1,344 supplied speakers and 63 source provinces support documented subgroup reporting, not universal coverage; the lowest province supports are 10 speakers. VN-SLU has no speaker/region metadata. Its released test count is **2,401 versus the paper’s 2,454**; that discrepancy is recorded, not repaired or reopened. Model-training overlap remains unknown.
- Individual reviews are selective; unresolved numeric/entity mappings and reference conventions limit interpretation. Both evaluation outputs are exposed through post-result analysis and must not be represented as unseen development holdouts. **Keep completed evaluation records separate from training data**; do not turn either system’s output into automatic gold.
- Existing rights questions remain unresolved: ViMD’s recorded CC BY-NC-ND 4.0 is not a blanket remote-processing/training/redistribution authorization; VN-SLU’s release license is unspecified; applicable provider output-training permissions are not verified. Historical completed requests do not establish those permissions. No new legal/terms check, provider contact or publication occurred here. Off-machine backup and actual spending are not established by local artifacts.
